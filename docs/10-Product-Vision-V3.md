## 6. Risques produit et mitigations

| Risque | Impact | Mitigation |
|--------|--------|------------|
| Gamification trop complexe | Confusion, churn | Progression progressive, tutoriels |
| Chat vocal = toxicité | Reputation | Modération auto + signalement + clubs privés uniquement |
| ELO = frustration débutant | Tables inaccessibles | Matchmaking skill-based + tables "Débutant" |
| Clubs inactifs | Plateforme morte | Events clubs automatiques, récompenses club actif |
| Tournois = wait time | Abandon | Side games (domino) pendant attente, notification push |
| VIP = pay-to-win perception | Injustice | VIP = confort, pas avantage jeu |
